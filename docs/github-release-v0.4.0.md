# Games Puzzle 0.4.0

В каталоге 22 фотографии. Иконка приложения — фрагмент фото «Мраморная стена Рускеалы» (Wikimedia Commons). Неудачный обмен не откатывает плитки: они просто остаются на новых местах. Можно включить проверку обновлений при запуске.

Игрок меняет местами незафиксированные фрагменты (перетаскивание или два нажатия). Ход остаётся, только если после него две части картинки совпали по общему краю: тогда они встают на свои места и больше не двигаются. Иначе плитки остаются на новых позициях (возврата назад нет).

## Что нового

- Каталог: **22** фотографии России из Wikimedia Commons с обновлёнными авторами и лицензиями.
- Иконка приложения — фрагмент фото «Мраморная стена Рускеалы»; источник и лицензия указаны в «Авторы».
- При неудачном обмене красной вспышки и отката нет: плитки остаются на новых местах.
- Победа: всегда показываются время и ходы этого запуска, а при улучшении результата — новые лучшие показатели независимо от переключателя отображения статистики во время игры.
- В настройках: «Проверять обновления при запуске» (по умолчанию выкл.). Если включено, при новой версии диалог показывается на каталоге; «Отмена» откладывает это обновление. Кнопка «Проверить обновления» по-прежнему всегда показывает changelog.

Интерфейс на русском. Минимум Android 8.0, портрет.

## Установка

Скачайте `games-puzzle-0.4.0.apk` из файлов этого релиза. Можно поставить поверх 0.3.0, если предыдущая сборка подписана тем же ключом.

Android может попросить разрешить установку из неизвестных источников.
