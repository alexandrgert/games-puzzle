# Games Puzzle 0.7.0

## Что нового

- Добавлены **10 вертикальных фотографий территории России** разных времён года по свободным лицензиям. Каталог вырос с 72 до **82** фотографий; прежние снимки сохранены.
- Новая подборка: 2 весенних, 3 летних, 3 осенних и 2 зимних снимка — от Москвы и Санкт-Петербурга до Алтая и Камчатки.
- Игровое поле показывает фотографию **целиком, без обрезки и растяжения**, сохраняя её пропорции. Размер поля подстраивается под доступное место на экране.
- Для новых фотографий указаны автор, лицензия и ссылка на источник в экране «Авторы».
- При повторной обработке новых фотографий сохраняются полный кадр и правильная ориентация; квадратная обрезка к ним не применяется.

Сетки 5×5, 6×6, 8×8, 10×10 и 12×12 доступны для каждой фотографии. Сохранение активной партии и исключение времени в фоне из таймера сохранены.

## Системные требования

- Android 8.0 (API 26) и новее.
- Телефон в портретной ориентации.
- Интернет нужен для проверки и загрузки обновлений; встроенные фотографии доступны офлайн.

## Установка

После публикации релиза скачайте `games-puzzle-0.7.0.apk` из его файлов. Обновление можно установить поверх 0.6.0 при подписи тем же ключом. Android может попросить разрешить установку из неизвестных источников.
