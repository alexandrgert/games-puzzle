# Games Puzzle 0.3.0

В каталоге 22 фотографии. Иконка приложения — фрагмент озера Джангысколь. Неудачный обмен подсвечивает только две плитки. Можно включить проверку обновлений при запуске.

Игрок меняет местами незафиксированные фрагменты (перетаскивание или два нажатия). Ход остаётся, только если после него две части картинки совпали по общему краю: тогда они встают на свои места и больше не двигаются. Иначе плитки возвращаются назад.

## Что нового

- Каталог: **22** фотографии России (добавлено 10 снимков Wikimedia Commons).
- Иконка приложения — фрагмент фото «Осень на озере Джангысколь» (Discoverynn, CC BY-SA 4.0); автор указан в «Авторы».
- При откате обмена красная вспышка только на двух плитках, не на всём поле.
- В настройках: «Проверять обновления при запуске» (по умолчанию выкл.). Если включено, при новой версии диалог показывается на каталоге; «Отмена» откладывает это обновление. Кнопка «Проверить обновления» по-прежнему всегда показывает changelog.

Интерфейс на русском. Минимум Android 8.0, портрет.

## Установка

Скачайте `games-puzzle-0.3.0.apk` из файлов этого релиза. Можно поставить поверх 0.2.0, если та сборка с того же ключа.

Android может попросить разрешить установку из неизвестных источников.
