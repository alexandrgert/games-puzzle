# Games Puzzle 0.8.3

В игре теперь **132 фотографии России**: к прежним 82 добавлены 50 новых вертикальных снимков.

- **New**: отметка на фотографиях новой подборки, которые ещё ни разу не собраны на этом устройстве. После первой полной сборки на любой сложности отметка исчезает; победы, сохранённые до обновления, тоже учитываются. Открытие фотографии или начало партии не убирает отметку. Это локальный прогресс, а не общая статистика всех игроков.
- **★ рядом с New**: фотография впервые добавлена в каталог игры. Последние 50 снимков получают отметку **New ★** до первой сборки на устройстве.
- Новые 50 фотографий теперь находятся в начале каталога, в том числе при фильтрации по категории и сезону.
- Новые сюжеты: цветущие сады и мостики, горные озёра, водопады, осенние отражения и зимние пейзажи.
- Фотографии показываются целиком, без обрезки и растяжения. Представлены все четыре времени года.
- У каждого снимка сохранены авторство, свободная лицензия и ссылка на источник. Для двух фотографий с некорректной датой сезон оставлен без уточнения.
- Все прежние изображения и их ID сохранены: результаты и сохранённые партии остаются связаны со своими фотографиями.

**Установка:** скачайте `games-puzzle-0.8.3.apk` из файлов релиза и установите поверх предыдущей версии.

Android 8.0 и новее. Русский интерфейс.
