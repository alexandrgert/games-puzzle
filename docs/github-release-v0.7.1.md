# Games Puzzle 0.7.1

## Что нового

- Все 82 встроенные фотографии теперь вертикальные: 72 квадратных снимка заменены новыми, последние 10 сохранены без изменений.
- Сохранены шесть категорий и прежнее количество фотографий в каждой: природа, вода, животные, птицы, деревья и цветы.
- Изображения показываются целиком, без обрезки и растяжения. Оригиналы проверены с учётом EXIF-ориентации.
- Для каждой фотографии сохранены авторство, свободная лицензия и ссылка на Wikimedia Commons. Авторство фотографии иконки остаётся на экране «Авторы» после удаления её пазла из каталога.
- Новые фотографии получили отдельные идентификаторы, чтобы записи и сохранённые партии прежних картинок не переносились на другие изображения. Партии по удалённым фотографиям продолжить нельзя.

## Установка

Скачайте `games-puzzle-0.7.1.apk` из файлов релиза. Обновление можно установить поверх 0.7.0 при подписи тем же ключом. Требуется Android 8.0 или новее. Встроенные фотографии доступны офлайн.
