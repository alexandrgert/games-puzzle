# Замена 72 квадратных фотографий на вертикальные

Подборка проверена 1 октября 2026 года. В каталоге остаются 82 фотографии: 72 новых и последние 10 без изменений. Сохранено количество фотографий по каждой категории. Все оригиналы вертикальные после применения EXIF-ориентации, шириной не менее 1200 пикселей. Обработка: полный кадр, пропорциональное уменьшение до 2000 пикселей по длинной стороне, WebP; миниатюра до 256 пикселей. Исходники не увеличиваются.

[Галерея всех 72 фотографий](portrait-replacements.html). [Машинный список замен, лицензий, размеров и SHA-256 оригиналов](../scripts/portrait_replacements.json). Новые ID отделяют записи и сохранённые партии от прежних изображений. Авторство фотографии иконки «Мраморная стена Рускеалы» сохранено отдельно в экране «Авторы».

Места проверены по описаниям, категориям или координатам Commons. Животные и часть птиц сняты в Московском зоопарке. Сезон указан по дате съёмки; при отсутствии месяца — `any`. Для магнолии использована дата в имени источника. Заснеженные мартовские снимки относятся к весне по календарной дате.
