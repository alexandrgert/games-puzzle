# Games Puzzle 0.2.0

Можно перетаскивать фрагменты на другие клетки. Появились сетки 8×8, 10×10 и 12×12. Поле больше не заезжает под строку времени и уведомлений.

Игрок меняет местами незафиксированные фрагменты (перетаскивание или два нажатия). Ход остаётся, только если после него две части картинки совпали по общему краю: тогда они встают на свои места и больше не двигаются. Иначе плитки возвращаются назад.

## Что нового

- Перетаскивание фрагмента на другой; по-прежнему можно выбрать два тапом.
- Неудачный обмен кратко показывается и откатывается.
- Сетки **5×5**, **6×6**, **8×8**, **10×10**, **12×12**.
- Игровое поле начинается ниже строки состояния и не перекрывает системную навигацию.
- Поле занимает место над кнопкой «Картинка».

Интерфейс на русском. Минимум Android 8.0, портрет.

## Установка

Скачайте `games-puzzle-0.2.0.apk` из файлов этого релиза. Можно поставить поверх 0.1.0, если та сборка с того же ключа.

Android может попросить разрешить установку из неизвестных источников.
