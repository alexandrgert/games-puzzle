# Games Puzzle 0.1.0

Первый Android-релиз. Это не «пятнашки»: картина режется на полную сетку без пустой клетки.

Игрок меняет местами любые незафиксированные фрагменты. Ход остаётся, только если после него две части картинки совпали по общему краю: тогда они встают на свои места на готовой фотографии и больше не двигаются. Иначе плитки возвращаются назад.

## Что нового

- Встроенный каталог: 12 фотографий России (природа, животные, птицы, водоёмы, деревья, цветы) с фильтром по сезону.
- Перед стартом — полный предпросмотр. Сетка **5×5** или **6×6** на выбор для каждой картины.
- Пазл из своей фотографии из галереи; можно удалить, если не подошёл.
- Статистика (время, ходы, лучшие результаты) по желанию, по умолчанию выключена.
- Проверка обновлений в настройках: всегда показывается changelog, затем загрузка APK.
- Экран «Авторы»: лицензии Wikimedia Commons (Public Domain / CC BY / CC BY-SA).

Интерфейс на русском. Минимум Android 8.0, портрет.

## Установка

Скачайте `games-puzzle-0.1.0.apk` из файлов этого релиза. Android может попросить разрешить установку из неизвестных источников.

Если уже стоит сборка, подписанная другим ключом, удалите её перед установкой. Локальные данные (свои фото и рекорды) при удалении приложения пропадут.
