# Games Puzzle 0.1.0

Первый Android-релиз Games Puzzle.

## Что нового

- Пазлы из встроенного каталога с фильтрами, предпросмотром и уровнями 5×5 и 6×6.
- Механика соединения совпадающих частей изображения с фиксацией собранных фрагментов.
- Импорт собственных фотографий и удаление пользовательских пазлов.
- Статистика лучших результатов и настройки приложения.
- Проверка обновлений через GitHub Releases, показ списка изменений и загрузка APK.
- Офлайн-доступ к встроенным изображениям и сведениям об их лицензиях.

## Установка

Скачайте `games-puzzle-0.1.0.apk` из файлов релиза и разрешите установку приложений из неизвестных источников, если Android запросит это.

Если ранее была установлена сборка, подписанная другим ключом, удалите её перед установкой этой версии. Локальные данные удалённого приложения при этом будут потеряны.
