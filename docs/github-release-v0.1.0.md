# Games Puzzle 0.1.0

Первый Android-релиз: картина режется на полную сетку без пустой клетки. Совпадающие края соединяются, фрагмент встаёт на своё место на готовой картине и больше не двигается.

## Что нового

- Встроенный каталог: 12 фотографий России (природа, животные, птицы, водоёмы, деревья, цветы) с фильтром по сезону.
- Перед стартом — полный предпросмотр; сетка **5×5** или **6×6** на выбор для каждой картины.
- Своя фотография из галереи: импорт квадратом (от 512 px, до 1200 px) и удаление, если пазл не подошёл.
- Необязательная статистика (время, ходы, лучшие результаты) — по умолчанию выключена.
- Проверка обновлений в настройках: всегда показывается changelog, затем загрузка сразу или после подтверждения.
- Экран «Авторы»: лицензии Wikimedia Commons (Public Domain / CC BY / CC BY-SA).

## Установка

Скачайте `games-puzzle-0.1.0.apk` из файлов этого релиза. Android может попросить разрешить установку из неизвестных источников.

Если уже стоит сборка, подписанная другим ключом, удалите её перед установкой. Локальные данные (свои фото и рекорды) при удалении приложения пропадут.

Минимум Android 8.0 (API 26). Ориентация: портрет.
