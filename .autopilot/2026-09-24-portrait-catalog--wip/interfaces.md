# Границы

- Каталог сохраняет JSON schema_version 1 и поля file/thumb/license/attribution/source_url.
- Снимки имеют собственное соотношение сторон; квадратная сетка n×n состоит из прямоугольных фрагментов.
- PlayScreen вписывает полное поле в доступную область, координаты нажатий и перетаскивания локальны для поля.
- Существующие файлы изображений и записи каталога остаются без изменений.
- Android-сборки и JVM-тесты запускаются только в CI.
