**Требования:** R07
**Blocked by:** 01
**Зона:** `docs/`

**Status:** ready

## Что должно заработать

Появляется черновик следующего GitHub Release, который описывает только фактически завершённые изменения этого прогона, ставит новый раздел первым и сохраняет историю предыдущих релизов ниже.

## Из брифа, дословно

> «как закончишь, подготовь черновик release notes»

## Разделы спецификации

История 9, решение о release notes и раздел «Вне рамок».

## Критерии приёмки

- [ ] Файл явно помечен как черновик и не утверждает, что релиз опубликован
- [ ] Новый раздел расположен первым и описывает сохранение партии, таймер, тесты и CI только по факту реализации
- [ ] Ниже включена накопительная история из существующих release notes без выдуманных изменений
- [ ] Указано ожидаемое имя APK с плейсхолдером следующей версии; `VERSION` не изменён
- [ ] GitHub Release не создаётся и внешняя публикация не выполняется
- [ ] Черновик явно говорит, что APK собирается только GitHub Actions и публикация допустима после зелёного CI
