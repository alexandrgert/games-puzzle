# Games Puzzle

Android-пазл по фотографии. Картина режется на полную сетку **без пустой клетки** — это не «пятнашки».

Игрок меняет местами любые незафиксированные фрагменты. Ход остаётся, только если после него две части картинки совпали по общему краю: тогда они встают на свои места на готовой фотографии и больше не двигаются. Иначе плитки возвращаются назад.

## Что внутри

- Встроенный каталог фотографий России: природа, животные, птицы, водоёмы, деревья, цветы; фильтр по сезону.
- Перед стартом — полный предпросмотр. Сетка **5×5** или **6×6** на выбор для каждой картины.
- Можно собрать пазл из своей фотографии из галереи и удалить его, если не подошёл.
- Статистика (время, ходы, лучшие результаты) по желанию, по умолчанию выключена.
- Обновления через GitHub Releases: в настройках показывается changelog, затем загрузка APK.

Интерфейс на русском. Минимум Android 8.0, портрет.

## Установка

Подписанный APK собирается на GitHub Actions и публикуется в [Releases](https://github.com/alexandrgert/games-puzzle/releases).
