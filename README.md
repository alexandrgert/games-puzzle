# Games Puzzle

Android-пазл по фотографии. Картина режется на полную сетку **без пустой клетки** — это не «пятнашки».

Игрок меняет местами любые незафиксированные фрагменты — перетаскиванием или двумя нажатиями. Ход остаётся, только если после него две части картинки совпали по общему краю: тогда они встают на свои места на готовой фотографии и больше не двигаются. Иначе плитки остаются на новых местах.

## Что внутри

- Встроенный каталог: **72** фотографии России (природа, животные, птицы, водоёмы, деревья, цветы) с фильтром по сезону.
- Перед стартом — полный предпросмотр. Сетка **5×5**, **6×6**, **8×8**, **10×10** или **12×12** на выбор для каждой картины.
- Можно собрать пазл из своей фотографии из галереи и удалить его, если не подошёл.
- Во время игры показ статистики (время и ходы) можно отключить; при победе результаты и лучшие показатели всё равно сохраняются и показываются.
- Обновления через GitHub Releases: в настройках всегда показывается changelog, затем загрузка APK. Можно включить проверку при запуске (по умолчанию выкл.).
- Интерфейс на русском.

## Системные требования

- Android 8.0 (API 26) и новее
- Телефон, портрет (рассчитано на ~20:9, в том числе Poco X7 и Poco X8 Pro Max)
- Интернет нужен только для проверки и загрузки обновлений

## Установка

Текущий релиз: [v0.5.1](https://github.com/alexandrgert/games-puzzle/releases/tag/v0.5.1). Скачайте `games-puzzle-0.5.1.apk` со страницы релиза. Можно поставить поверх 0.5.0 с того же ключа. Android может попросить разрешить установку из неизвестных источников.
