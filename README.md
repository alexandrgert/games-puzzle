# Games Puzzle

Android-пазл по фотографии. Картина режется на полную сетку **без пустой клетки** — это не «пятнашки».

Игрок меняет местами любые незафиксированные фрагменты — перетаскиванием или двумя нажатиями. Незафиксированные части обведены тонкой белой рамкой. Ход остаётся, только если после него две части картинки совпали по общему краю: тогда они встают на свои места на готовой фотографии и больше не двигаются. Иначе плитки остаются на новых местах. Когда все фрагменты уже на своих клетках, они фиксируются и показывается победа.

## Что внутри

- В версии **0.8.2** доступны **132 вертикальные фотографии России**: к прежним 82 добавлены 50 новых снимков садов, мостиков, цветов, горных озёр, водопадов и сезонных пейзажей. Все фотографии используются по свободным лицензиям; авторы и источники указаны в приложении. Новые 50 снимков находятся в начале каталога. Отметка **New** сохраняется до первой сборки фотографии на этом устройстве. Есть фильтры по категории и сезону.
- Игровое поле сохраняет пропорции фотографии и показывает её целиком, без обрезки и растяжения. Размер поля подстраивается под доступное место на экране.
- Перед стартом — полный предпросмотр. Сетка **5×5**, **6×6**, **8×8**, **10×10** или **12×12** на выбор для каждой картины.
- Можно собрать пазл из своей фотографии из галереи и удалить его, если не подошёл.
- Во время игры показ статистики (время и ходы) можно отключить; при победе результаты и лучшие показатели всё равно сохраняются и показываются.
- Открытая партия сохраняется на устройстве и восстанавливается после возвращения в приложение или перезапуска процесса; время в фоне не учитывается.
- Обновления через GitHub Releases: в настройках всегда показывается changelog, затем загрузка APK. Можно включить проверку при запуске (по умолчанию выкл.).
- Интерфейс на русском.

## Системные требования

- Android 8.0 (API 26) и новее
- Телефон, портрет
- Интернет нужен только для проверки и загрузки обновлений
