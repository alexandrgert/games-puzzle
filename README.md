# Games Puzzle

Android-пазл по фотографии. Картина режется на полную сетку **без пустой клетки** — это не «пятнашки».

Игрок меняет местами любые незафиксированные фрагменты — перетаскиванием или двумя нажатиями. Ход остаётся, только если после него две части картинки совпали по общему краю: тогда они встают на свои места на готовой фотографии и больше не двигаются. Иначе плитки возвращаются назад.

## Что внутри

- Встроенный каталог фотографий России: природа, животные, птицы, водоёмы, деревья, цветы; фильтр по сезону.
- Перед стартом — полный предпросмотр. Сетка **5×5**, **6×6**, **8×8**, **10×10** или **12×12** на выбор для каждой картины.
- Можно собрать пазл из своей фотографии из галереи и удалить его, если не подошёл.
- Статистика (время, ходы, лучшие результаты) по желанию, по умолчанию выключена.
- Обновления через GitHub Releases: в настройках показывается changelog, затем загрузка APK.
- Интерфейс на русском.

## Системные требования

- Android 8.0 (API 26) и новее
- Телефон, портрет (рассчитано на ~20:9, в том числе Poco X7 и Poco X8 Pro Max)
- Интернет нужен только для проверки и загрузки обновлений

## Установка

Текущий релиз: [v0.2.0](https://github.com/alexandrgert/games-puzzle/releases/tag/v0.2.0). Скачайте `games-puzzle-0.2.0.apk` со страницы релиза. Android может попросить разрешить установку из неизвестных источников.
